隐私政策

最后更新：2026 年 11 月 26 日 · 适用版本：1.1.0 及以后

一句话版本：PassForge 没有服务器，不会把数据传输到设备之外，也不出售或共享数据。 为提供核心功能，它会在本机临时处理生成的密码和密码框的最小字段信息；密码不上传、不保存。

PassForge 密码工坊（以下简称“PassForge”或“本扩展”）是一个完全在浏览器本地运行的 开源密码生成器。本政策说明本扩展会处理哪些数据、为什么处理，以及不会做什么。

1. 在本地处理的数据

为提供“生成强密码并复制或填入”的唯一功能，本扩展会在你的设备上临时处理以下信息。 这些信息不会被发送到开发者、服务器或任何第三方。

  • 生成的密码：使用浏览器提供的 crypto.getRandomValues() 在本地生成。密码显示在扩展弹窗中； 只有当你点击“复制”时才会写入系统剪贴板，只有当你点击“填入”或右键菜单项时 才会写入当前网页的密码框。密码不会写入扩展存储、浏览器历史、日志或远程服务。
  • 当前页面的最小字段信息：仅在你主动点击“填入”或右键菜单项时， 扩展会临时读取当前标签页中密码输入框的类型、可见性，以及 name、id、placeholder、 aria-label、autocomplete 等属性，用于判断该填哪个密码框、 是否需要同步确认密码框。该信息只在当次操作中使用，不保留、不传输，也不用于广告或分析。
  • 生成设置：密码长度、生成数量、启用的字符类型和是否排除易混淆字符， 通过 chrome.storage.local 保存在你的本机。这些设置不包含任何密码。
  • 剪贴板：只有当你点击“复制”或“全部复制”时，扩展才会把对应密码写入 系统剪贴板。剪贴板中的内容之后可能由操作系统或你安装的剪贴板管理器处理，这不属于 PassForge 的控制范围。

2. 扩展申请的权限

  • activeTab：仅在你点击“填入”或右键菜单项后， 临时获得当前标签页的访问权限，用于填入密码。不会在后台读取其他页面。
  • scripting：在用户主动触发时，把用于识别并填写密码框的 自包含脚本注入当前标签页。没有常驻内容脚本。
  • contextMenus：注册“自动生成密码”右键菜单项。
  • storage：在本机保存生成偏好设置，不保存密码。
  • clipboardWrite：在你点击复制按钮时写入剪贴板。

本扩展未申请 <all_urls> 或任何全站主机权限，也没有远程代码、 统计 SDK、广告 SDK 或后台数据上报。

3. 数据出售、共享与转让

不。PassForge 不会出售、出租、交易或与他人共享你的密码、浏览内容或任何个人信息。 扩展没有后端服务器，开发者无法访问你在本机生成或填写的密码。我们不会将数据用于 个性化广告、兴趣画像、信用评估或与本扩展单一用途无关的目的。

4. 数据保留与删除

密码本身从不被 PassForge 保留；关闭弹窗后，扩展不再持有生成结果。生成设置会保留在本机， 直到你修改设置或卸载扩展。卸载扩展通常会使 Chrome 清除其本地存储。你随时可以在弹窗中 调整或恢复设置，不需要创建账户。

5. 安全

密码使用浏览器加密随机数生成，并经拒绝采样避免取模偏差；代码中没有 Math.random() 降级路径。扩展不加载远程代码，权限保持最小化，源码公开可审计。 但请注意：任何本机软件都无法消除设备被恶意软件控制、浏览器被调试或剪贴板被其他程序读取的风险。 重要账户建议使用长度 16 位以上的密码，并保存在可信的密码管理器中。

6. 与 Chrome Web Store 用户数据政策的一致性

PassForge 对通过 Chrome API 获得的信息的使用，仅限于提供本扩展明确披露的单一用途： 在本机生成密码，并在用户主动操作时复制或填入密码。该使用遵守 Chrome Web Store User Data Policy，包括其 Limited Use 要求。我们不会将数据用于个性化广告，不会出售数据， 不会允许人工读取你的密码，也不会在不符合政策的情况下转让数据。

7. 联系与反馈

对本政策或数据处理有任何疑问，请通过 GitHub Issues 联系： github.com/BrathonBai/passforge/issues 。请勿在公开 Issue 中粘贴任何真实密码或账户凭据。

8. 政策变更

如果本扩展的数据处理方式发生实质变化，我们会更新本页面和仓库中的 PRIVACY.md，并在新版本说明中标注。继续使用新版本即表示你了解更新后的政策。

English summary. PassForge is a local-first, open-source Chrome password generator. It has no backend and does not transmit, sell, or share personal data; password generation and filling happen locally on the device. Generated passwords are created locally with crypto.getRandomValues(), are never stored by the extension, and are only copied or filled into a page when the user explicitly requests it. When filling, the extension temporarily reads minimal password-field metadata (type, visibility, and identifying attributes) to locate the target and confirmation fields; this information is used only for that action and is not retained or transmitted. The only persistent data is generation preferences stored locally in chrome.storage.local, which contain no passwords. The extension uses no remote code, analytics, or advertising. Its use of Chrome API data is limited to providing the extension's single purpose, in accordance with the Chrome Web Store User Data Policy, including the Limited Use requirements.
